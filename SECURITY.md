# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately via
[GitHub Security Advisories](https://github.com/tpc-pascal/folio/security/advisories/new),
or reach out to the maintainer through the
[GitHub profile](https://github.com/tpc-pascal).

When reporting, include:

- A description of the vulnerability and its impact
- Steps to reproduce, or a proof of concept if available
- The affected version or commit, if known

You will receive an acknowledgement as soon as possible. We will work with you
on a fix and coordinate disclosure.
